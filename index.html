プライバシーポリシー(HikingBearくん)

本アプリ「HikingBearくん」は、開発者本人(熊谷)が個人的に利用するために開発した非公開のツールです。

  • 本アプリは Google Tasks API を通じて、開発者本人のGoogleタスクの未完了タスク一覧を取得し、LINEに通知する目的にのみ使用します。
  • 取得したデータは開発者本人以外の第三者に提供・共有することはありません。
  • 取得したデータは通知作成の目的にのみ使用し、それ以外の用途には使用しません。
  • 取得したデータをサーバー等に保存することはなく、通知処理の都度取得します。
  • 本アプリは開発者本人のみが利用する前提であり、第三者への提供・配布は行っていません。
